## Featured projects

### [Blendmentation](https://csmx.eu/tools/blendmentation)

An open-source Python library that generates synthetic, augmented training datasets for computer vision from Blender scenes. You build the pipeline from composed steps, the same way you would with torchvision or albumentations: randomize the scene, render images with masks, bounding boxes, keypoints and 6D poses, restore the scene, and export to COCO, YOLO, Pascal VOC or BOP.
